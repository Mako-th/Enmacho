# 幻想閻魔帳（Enmacho）

東方花映塚（東方Project 第 9 弾、ver.1.50a）のプレイとリプレイを記録・分析する、Windows 用の非公式ツールです。

- ゲームの実行中メモリを外部から読み取り、対戦の進行（ラウンドの開始・終了、キャラクター、結果など）を記録します。
- リプレイファイル（`replay\th9_NN.rpy`）を復号して読み、同じ形で記録に取り込みます。
- 記録した対戦を、画面のタブ（プレイ・履歴・リプレイ・統計）から振り返れます。

このツールは**上海アリス幻樂団の公式ツールではありません**。東方Project の二次創作物として、
個人が作成・公開しています。ゲーム本体（`th09.exe`）やゲームのデータは含みません。

## 動く環境

- Windows 11
- 東方花映塚 ver.1.50a（ゲーム本体は、お手持ちのものを使います）
- 花映塚用の vpatch（`vpatch.exe`）。走査（下の「はじめに」の 5）を倍速で回すのに使います。`th09.exe` と同じフォルダに入れておいてください。

## はじめに（初めて使うとき）

### 1. 展開する

zip を右クリックして「すべて展開」を選びます。`Enmacho` フォルダができ、その中に `EnmaCho.exe` などが入っています。
zip を開いた画面から `EnmaCho.exe` を直接起動せず、展開してから使ってください。

`Enmacho` フォルダは、デスクトップやドキュメントなど好きな場所に置いてかまいません。
ただし Program Files の下には置かないでください（記録の DB を書き込めません）。

リプレイは、花映塚のフォルダ（`th09.exe` のあるフォルダ）と、そのユーザー側のデータのフォルダ
（花映塚を Program Files の下に入れているときに Windows が `%LOCALAPPDATA%\VirtualStore` の下に作るフォルダ）から、中のフォルダも含めて読みます。
花映塚のフォルダは、監視で花映塚を見つけたときに自動で覚えます。
先に指定したいときや、ほかの場所にあるリプレイも取り込みたいときは、下の「リプレイのフォルダを指定する」を見てください。

### 2. 起動する

`EnmaCho.exe` をダブルクリックします。`EnmaCho_drive.exe` はこのツールが裏で動かすもので、直接起動する必要はありません。

- 初めて起動すると「Windows によって PC が保護されました」と出ることがあります。「詳細情報」を押すと出る「実行」を押してください。
- ウイルス対策ソフトが警告を出すことがあります。理由は下の「ゲームに組み込むファイルについて」にあります。

### 3. 自分の名前を登録する

統計のタブは、既定では自分のプレイと自分のリプレイだけを数えます。リプレイが自分のものかは、リプレイに付いている名前で見分けます。

1. 上の帯の「設定」を押し、「記録」タブを開きます。
2. 「自分の名前」の下の欄に、リプレイを保存するときに付けている名前を入れて「足す」を押します。名前を複数使っているなら、全部足します。
3. 「保存」を押します。

名前を 1 つも登録していないと、取り込んだリプレイはどれも「他人のリプレイ」として扱われ、統計に出ません
（統計の「他人のリプレイも含める」を入れると数えます）。

### 4. リプレイを取り込む

ゲームは起動していなくてかまいません。

1. 上の帯の「走査」を押し、開いた窓の「既存Replay一括登録」を押します。
2. 花映塚のフォルダ・ユーザー側のデータのフォルダ・追加の置き場（どれも中のフォルダを含む）のリプレイが登録され、「リプレイ」タブに並びます。

ここで入るのは、リプレイファイルから読める内容（モード・キャラ・難易度・スコアなど）です。
「リプレイ」タブの「数値の推移」と「被弾窓」は、次の走査で入ります。
自分の名前を後から足したり変えたりしたときは、もう一度「既存Replay一括登録」を押すと、登録済みのリプレイも判定し直します。
一度登録した後は、`EnmaCho.exe` を起動するたびに同じ登録が自動で 1 回流れます（フォルダの中で移動したリプレイも登録し直します）。

### 5. 走査する（リプレイを自動で再生して記録する）

走査は、登録したリプレイをゲームで 1 本ずつ再生し、再生中の毎フレームのデータを記録します。
これで「数値の推移」と「被弾窓」が見られるようになります。

1. 花映塚を `vpatch.exe` から起動し、タイトル画面にしておきます。
   `th09.exe` から直接起動すると倍速にならず、1 本ごとにリプレイの長さと同じだけ時間がかかります。
   ウィンドウモードにしておくと、進み具合をこのツールの窓で見ながら待てます。
2. 上の帯の「監視」が動いていたら止めます（監視と走査は同時に動かせません）。
3. 上の帯の「走査」を押します。モード・対戦区分・難易度・キャラで絞り込めます（何も選ばなければ全部が対象です）。
   「走り方」は、既定の「新規のみ走査して DB 追加」のままで使います。
4. 「予定を見る」で、対象の本数とかかる時間の見込みを確かめます。
5. 「走査を始める」を押します。このツールがゲームを操作して、リプレイを 1 本ずつ再生します。進み具合は上の帯に出ます。

4 の取り込みをせずに初めて走査を始めたときは、走査の前に自動でリプレイを取り込みます。

走査している間は:

- ゲームを操作しないでください。走査の間は、ゲームへのキーボードとパッドの入力をこのツールが止めています。
- ゲームの窓をドラッグしないでください。ドラッグしている間はゲームが止まります。
- ゲームの窓は前面になくてかまいません。ほかの作業をしていても走査は進みます。
- ゲームは終了しないでください。
- 止めたいときは、上の帯の「停止」を押します。そこまでに終わった分は残ります。
  もう一度「新規のみ走査して DB 追加」で始めると、残りから続けます。

走査は、ゲームのリプレイの 25 番（`th9_25.rpy`）の枠を借りて再生します。
25 番にリプレイが入っていれば、走査の間は `th9_25.rpy.tickscan.bak` という名前で退避し、終わったら元に戻します。
途中でこのツールが止まってしまったときも、次に走査を始めたときに元に戻します。

### 6. 自分のプレイを記録する（監視）

1. 上の帯の「監視」を押します。左の印が赤い丸になれば動いています。
2. 花映塚を起動して遊びます。このツールとゲームは、どちらを先に起動してもかまいません（監視はゲームの起動を待ちます）。
3. 遊んでいる間の数字は「プレイ」タブに、終わった対戦は「履歴」タブに出ます。

止めるときは、もう一度「監視」を押します。
このツールの窓が前面にあるときは、F9 キーでも入り切りできます。
「設定」→「記録」タブの「花映塚を見つけたら監視を自動で入り切りする」を入れると、ゲームの起動と終了に合わせて監視が自動で入り切りします
（このとき「監視」ボタンは押せなくなり、「監視: 自動」と出ます）。

## 困ったとき

走査や監視が途中で止まったときは、上の帯にその理由の行が出ます。
それまでの経過は、`EnmaCho.exe` と同じフォルダの `data\logs\th09_log_日付.tsv` に 1 行ずつ残ります。

| 出た字・起きたこと | 直し方 |
|---|---|
| 「th09.exe が見つかりません。ゲームを起動してください。」 | 花映塚を起動してから、もう一度走査を始めます |
| 「ゲームの replay フォルダが見つかりません。」 | 下の「リプレイのフォルダを指定する」のとおり、ゲームが読む `replay` フォルダを `replay_paths.txt` に書きます |
| 「走査と通常の監視は同時に動かせません」 | 上の帯の「監視」を止めてから、もう一度走査を始めます |
| 走査が「タイトルへ戻れない」と言って止まった | ゲームを手でタイトル画面へ戻してから、もう一度走査を始めます |
| 走査が倍速にならない | 花映塚を `vpatch.exe` から起動し直します |
| 統計に何も出ない | 「自分の名前」を登録して（「はじめに」の 3）、「既存Replay一括登録」を押し直します |
| 「リプレイ」タブの「数値の推移」「被弾窓」が空 | そのリプレイがまだ走査されていません（「はじめに」の 5） |

## リプレイのフォルダを指定する

上の帯の「設定」を押し、「記録」タブのいちばん下の 3 行で指定します。指定したら「保存」を押してください。
次のリプレイの登録（起動時の自動登録・Replay保存監視・既存Replay一括登録）から効きます。

- **ゲームのフォルダ**: 「選ぶ…」を押し、`th09.exe` のあるフォルダを選びます。
  監視で花映塚を見つけると自動で覚えるので、監視を使っていれば選ばなくてもかまいません。
  「ゲームの replay フォルダが見つかりません」と出たときは、ここを選んでください。
- **ユーザー側のデータ**: ゲームのフォルダから決まるので、表示だけです（無ければ「ありません」と出ます）。
- **追加の置き場**: ほかの場所にリプレイを置いているときは、「足す…」を押してフォルダを選びます。いくつでも足せます。外すときは、一覧で 1 行選んで「外す」を押します。

どれも中のフォルダまで全部見ます。

- 追加の置き場は、`EnmaCho.exe` と同じフォルダの `replay_paths.txt` に 1 行に 1 つずつ入ります。メモ帳で直接書いてもかまいません（文字コードは UTF-8 のまま保存してください。`#` で始まる行は読み飛ばします）。
- 対戦ツール（adonis2）が自動保存したリプレイは、保存先がゲームのフォルダかユーザー側のデータのフォルダの中なら自動で取り込みます。ほかの場所へ保存しているときは、そのフォルダを追加の置き場に足してください。
- 走査でゲームにリプレイを再生させるときは、ユーザー側のデータのフォルダに `replay` フォルダがあればそこ、無ければゲームのフォルダの `replay` フォルダの 25 番の枠を使います。

## ゲームに組み込むファイルについて

走査などでは、`native\th09_inject\build\th09_inject.exe` と `native\th09_tickhook\build\th09_tickhook.dll` の
2 ファイルをゲームのプロセスへ組み込み、毎フレームのデータを取ります。
そのため、Windows のウイルス対策ソフトが警告を出すことがあります（外部プロセスのメモリを操作するツールに共通の挙動です）。
この 2 ファイルは、`EnmaCho.exe` から見て今の場所に置いたままにしてください。移したり消したりすると、走査ができません。

## 記録の置き場所

記録の DB（`th09_tracker.sqlite3`）と設定（`config.json`）は、`EnmaCho.exe` と同じフォルダに作られます。
被弾窓などの毎フレームのデータは、その下の `data\layer0\th09_ticks.db` に入ります。
どちらも、最初に記録するとき（リプレイの登録や走査）に作られます。
このツールを別の場所へ移すときは、これらも一緒に移してください。

## 画面ごとの使い方

### 上の帯

- **監視**: 自分のプレイを記録します（「はじめに」の 6）。押すたびに入り切りします。
- **走査**: リプレイを自動で再生して記録する窓を開きます。
  「対象にするフォルダ」とモード・対戦区分・難易度・キャラで絞り込み、「予定を見る」で対象を確かめてから「走査を始める」を押します。
  走っている間は、上の帯の「停止」で止められます。
- **既存Replay一括登録**（走査の窓の中）: 再生はせず、リプレイファイルを読んで記録に登録だけします。
  被弾窓や数値の推移は入りませんが、履歴・リプレイ・統計のタブで一覧や集計に使えます。
- **配信パネル**: 配信用の縦長の窓（SB / PB / Target / WR）を開閉します。OBS のウィンドウキャプチャで取り込めます。
  出す項目・背景色・字の大きさは、窓を右クリックしても変えられます。
- **設定**: 下の「設定」の節を見てください。

### プレイ

ゲームを監視している間、いまの対戦の数字を表示します（読むだけのタブです）。
監視は、上の帯の「監視」、設定の「記録」タブの「花映塚を見つけたら監視を自動で入り切りする」、「監視を切り替えるキー」（F9）のどれかで入り切りします。
表示する項目は、設定の「統計」タブの「プレイタブに出す項目」で選べます。

### 履歴

記録したセッションの一覧です。上の「実プレイ」「リプレイ再生」「全て」で切り替えます。

- 行を右クリックして「個別詳細を開く」を選ぶと、そのセッションの詳細が開きます。
- 行を選んで Delete キー（または右クリック）で削除できます。確認で「はい」を押したときだけ消えます。
- 残す件数は、設定の「履歴」タブで決められます。

### リプレイ

登録したリプレイの一覧です。「Story / Extra」と「Match」で切り替え、キャラや相手、難易度などで絞り込めます。

- 「自分のみ」で自分のリプレイだけを出します。自分の名前は、設定の「記録」タブで登録します。
- 行を押すと詳細が開き、「概要」「数値の推移」「被弾窓」を見られます。数値の推移と被弾窓は、走査したリプレイだけに入ります。
- 行を右クリックすると、リプレイファイルの場所をエクスプローラーで開けます。

### 統計

記録した対戦を集計します。自キャラ・相手キャラ・タグで絞り込み、要約カードと内訳表で見ます。

- 「全組み合わせ表」で、キャラの組み合わせごとの表を開きます。
- 既定では他人のリプレイを数えません。「他人のリプレイも含める」で入れます。
- 数字の意味は、画面の「この画面の数字について」に書いてあります。
- 表の列の並び・表示は、設定の「統計」タブで変えられます。

### 設定

| タブ | 変えられるもの |
|---|---|
| 記録 | 監視の入り切り、リプレイの再生も記録するか、控え（バックアップ）の残し方、自分の名前 |
| 被弾窓 | 被弾窓を取るか、窓の前後の長さ、窓を取るモード |
| 履歴 | 中断・リプレイの履歴と完走の履歴を残す件数 |
| 統計 | 統計に出す区分、プレイタブに出す項目、表の列 |
| 配信 | 配信パネルに出す項目、窓の大きさ、背景色、字の大きさ |
| 目標 | 配信パネルに出す Target と WR |

## 控え（バックアップ）について

- 走査の窓の「**走る前に控えを取る**」（既定: オン）: 走査の前に、記録の DB を `data\backup\` へ写します。
  外すと控えを取りません。容量は減りますが、走査の途中で何かあったときに戻す先がなくなります。
- 設定の「記録」タブの「**控えは「完成した 1 つ」だけ残す（未完成の控えは消す）**」（既定: オン）:
  走査が新しい控えを取れたら、それより前の控えを消して 1 組だけ残します。外すと、控えが走査のたびに増えていきます。

## 記録の容量の目安

作者の手元の記録（1,677 本・約 228 時間分）での実測です。容量のほとんどは被弾窓（被弾の前後のデータ）が占めます。

| | 合計 | 1 本あたり | 1 時間あたり |
|---|---:|---:|---:|
| 全体 | 8.7 GB | 5.2 MB | 38 MB |
| 被弾窓 | 7.8 GB | 4.6 MB | 34 MB |
| 毎フレームのデータ | 0.76 GB | 0.45 MB | 3.3 MB |
| 記録の DB | 0.09 GB | 0.05 MB | 0.4 MB |

1 本の長さや被弾の数によって増え方は変わります。
既定の設定では走査の前に DB の控え（バックアップ）を 1 組取って残すので、空き容量は上の 2 倍ほどを見込んでください
（控えを取らない設定にもできます。「控え（バックアップ）について」を見てください）。

## 建て方

### 記録・分析の画面（C#）

.NET SDK（`csharp/global.json` に書かれた版）が要ります。

```
dotnet publish -c Release -r win-x64 csharp/TH09.Drive/TH09.Drive.csproj
dotnet publish -c Release -r win-x64 csharp/TH09.Shell/TH09.Shell.csproj
```

それぞれのプロジェクトの `bin/Release/<版>/win-x64/publish/` にできる exe と DLL を、同じフォルダに集めます（`EnmaCho.exe` と `EnmaCho_drive.exe` が隣どうしになるように）。

### 注入用の 2 ファイル（C、32bit）

`th09.exe` は 32bit（PE32/i686）なので、注入する DLL とインジェクタも 32bit でビルドする必要があります。
64bit 用の MinGW では `-m32` が使えないため、**i686 版のツールチェーンが別に要ります**。

1. https://github.com/skeeto/w64devkit/releases から `w64devkit-x86-<版>.7z.exe`（自己解凍 7z）を取得します。
2. `C:\toolkit\_x86tmp` へ展開します（`C:\toolkit` へ直接展開すると、既存の 64bit 版があれば上書きします）。
3. `C:\toolkit\_x86tmp\w64devkit` を `C:\toolkit\w64devkit-i686` へ移動します。
4. 別の場所へ入れた場合は、環境変数 `TH09_I686_BIN` に `bin` ディレクトリを指定します。

準備ができたら、次の 2 本を実行します。

```
native\th09_tickhook\build.bat
native\th09_inject\build.bat
```

できた `th09_tickhook.dll` と `th09_inject.exe` は、`EnmaCho.exe` のあるフォルダの下の`native\th09_tickhook\build\` と `native\th09_inject\build\` へ、それぞれ置きます。
