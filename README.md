# 幻想閻魔帳（Enmacho）

東方花映塚（東方Project 第 9 弾、ver.1.50a）のプレイとリプレイを記録・分析する、Windows 用の非公式ツールです。

- ゲームの実行中メモリを外部から読み取り、対戦の進行（ラウンドの開始・終了、キャラクター、結果など）を記録します。
- リプレイファイル（`replay\th9_NN.rpy`）を復号して読み、同じ形で記録に取り込みます。
- 記録した対戦を、画面のタブ（プレイ・履歴・リプレイ・統計）から振り返れます。

このツールは**上海アリス幻樂団の公式ツールではありません**。東方Project の二次創作物として、
個人が作成・公開しています。ゲーム本体（`th09.exe`）やゲームのデータは含みません。

## 動く環境

- Windows 11
- 東方花映塚 ver.1.50a（ゲーム本体は、お手持ちのものを使います）
- 花映塚用の vpatch（`vpatch.exe`）。走査（下の「はじめに」の 5）を倍速で回すのに使います。このツールには含まれていません。`th09.exe` と同じフォルダに入れておいてください。

## 全体の流れ

初めて使うときは、次の順に進めます。詳しくは下の「はじめに」の同じ番号を見てください。

| 順 | すること | ゲーム |
|---:|---|---|
| 1 | zip を展開して、好きな場所に置く | 要らない |
| 2 | `EnmaCho.exe` を起動する（初めての確認は「後で」でよい） | 要らない |
| 3 | 設定で、自分の名前（リプレイに付けている名前）とリプレイのフォルダを決める | 要らない |
| 4 | リプレイのフォルダの中から取り込むフォルダを選んで取り込む（既存Replay一括登録） | 要らない |
| 5 | 取り込んだリプレイをゲームで自動再生して、細かいデータを取る（走査） | `vpatch.exe` から起動しておく |
| 6 | 自分のプレイを記録する（監視） | 遊ぶ |

4 までで、「リプレイ」タブの一覧と「統計」タブの集計が出ます。
5 の走査をすると、リプレイごとの「数値の推移」と「被弾窓」も見られるようになります。
6 の監視は、4・5 とは別に、これから遊ぶ対戦を記録するものです。リプレイを保存しなくても記録されます。
「履歴」タブには、5 の走査と 6 の監視で記録したものが並びます。

このツールが扱うリプレイは、3 で決める「リプレイのフォルダ」の中にあるものです。
4 と 5 では、その中からさらに「対象にするフォルダ」を選んで絞ります。

2 回目からの使い方は「ふだんの使い方」、記録の置き場所・容量・バックアップ・版の入れ替えは「管理する」を見てください。

## はじめに（初めて使うとき）

### 1. 展開して置く

zip を右クリックして「すべて展開」を選びます。`Enmacho` フォルダができ、その中に `EnmaCho.exe` などが入っています。
zip を開いた画面から `EnmaCho.exe` を直接起動せず、展開してから使ってください。

`Enmacho` フォルダは、デスクトップやドキュメントなど好きな場所に置いてかまいません。
ただし Program Files の下には置かないでください（記録の DB を書き込めません）。
記録や設定は、すべてこの `Enmacho` フォルダの中に作られます（「管理する」の「記録の置き場所」）。

### 2. 起動する

`EnmaCho.exe` をダブルクリックします。`EnmaCho_drive.exe` はこのツールが裏で動かすもので、直接起動する必要はありません。

- 初めて起動すると「Windows によって PC が保護されました」と出ることがあります。「詳細情報」を押すと出る「実行」を押してください。
- ウイルス対策ソフトが警告を出すことがあります。理由は下の「ゲームに組み込むファイルについて」にあります。
- 初めて起動すると「記録用のデータベースがまだありません。作ってリプレイを登録しますか？」と聞かれます。
  この時点では取り込むフォルダをまだ選んでいないので、「後で」を押して 3 へ進んでください
  （「作って登録する」を押しても「フォルダが一つも指定されていません。」と出るだけで、何も変わりません）。
  記録用のデータベースは、4 の取り込みか 6 の監視で初めて記録するときに作られます。

### 3. 設定する（自分の名前とリプレイのフォルダ）

上の帯の「設定」を押し、「記録」タブを開きます。

1. **自分の名前**: 「自分の名前」の下の欄に、リプレイを保存するときに付けている名前を入れて「足す」を押します。名前を複数使っているなら、全部足します。
2. **ゲームのフォルダ**: 「選ぶ…」を押し、`th09.exe` のあるフォルダを選びます。
   走査はこのフォルダ（またはその「ユーザー側のデータ」）の `replay` フォルダを使って、ゲームにリプレイを再生させます。
3. **追加の置き場**: ゲームのフォルダの外にもリプレイを置いているなら、「足す…」でそのフォルダを足します。
4. 「保存」を押します。

統計のタブは、既定では自分のプレイと自分のリプレイだけを数えます。リプレイが自分のものかは、リプレイに付いている名前で見分けます。
名前を 1 つも登録していないと、取り込んだリプレイはどれも「他人のリプレイ」として扱われ、統計に出ません
（統計の「他人のリプレイも含める」を入れると数えます）。

ゲームのフォルダ・ユーザー側のデータ・追加の置き場の 3 つを合わせたものが、このツールの「リプレイのフォルダ」です（詳しくは下の「リプレイのフォルダを指定する」）。

### 4. リプレイを取り込む

ゲームは起動していなくてかまいません。

1. 上の帯の「走査」を押し、開いた窓の「対象にするフォルダ」の「追加…」で、取り込みたいリプレイのあるフォルダを選びます。いくつでも足せます。
   ふつうは花映塚のフォルダ（`th09.exe` のあるフォルダ）の中の `replay` フォルダです。
   花映塚を Program Files の下に入れている場合、保存したリプレイは「ユーザー側のデータ」
   （`%LOCALAPPDATA%\VirtualStore\Program Files (x86)\…\replay` のような、Windows が作る別のフォルダ）に入っていることがあります。
2. 「既存Replay一括登録」を押します。選んだフォルダ（中のフォルダを含む。「フォルダは直下だけ」を入れると直下だけ）のリプレイが登録され、「リプレイ」タブに並びます。
   終わると、上の帯に件数が出ます。

選べるのは、3 で決めたリプレイのフォルダの中だけです。
外のフォルダを選ぶと「追加の置き場にも足してから選びますか？」と聞かれ、「足す」を押すと、追加の置き場に足してから選びます。
選んだフォルダは、次に起動したときも残っています。
フォルダを 1 つも選んでいないと、「フォルダが一つも指定されていません。」と出て何も登録しません。
このツール自身のフォルダの `data` の中（走査のバックアップなど）は、選んだフォルダの中にあっても登録しません。

ここで入るのは、リプレイファイルから読める内容（モード・キャラ・難易度・スコアなど）です。
「リプレイ」タブの「数値の推移」と「被弾窓」は、次の走査で入ります。
自分の名前を後から足したり変えたりしたときは、もう一度「既存Replay一括登録」を押すと、登録済みのリプレイも判定し直します。

### 5. 走査する（リプレイを自動で再生して記録する）

走査は、登録したリプレイをゲームで 1 本ずつ再生し、再生中の毎フレームのデータを記録します。
これで「数値の推移」と「被弾窓」が見られるようになります。

1. 花映塚を `vpatch.exe` から起動し、タイトル画面にしておきます。
   `th09.exe` から直接起動すると倍速にならず、1 本ごとにリプレイの長さと同じだけ時間がかかります。
   ウィンドウモードにしておくと、進み具合をこのツールの窓で見ながら待てます。
2. 上の帯の「走査」を押し、「対象にするフォルダ」に走査したいリプレイのあるフォルダを選びます（4 で選んだものが残っています）。
   フォルダを 1 つも選んでいないと、「フォルダが一つも指定されていません。」と出て始まりません。
3. モード・対戦区分・難易度・キャラでさらに絞り込めます（何も選ばなければ、選んだフォルダの中の全部が対象です）。
   「走り方」は、既定の「新規のみ走査して DB 追加」のままで使います（ほかの走り方は下の表）。
4. 「予定を見る」で、対象の本数とかかる時間の見込みを確かめます。
5. 「走査を始める」を押します。このツールがゲームを操作して、リプレイを 1 本ずつ再生します。進み具合は上の帯に出ます。

4 の取り込みをせずに初めて走査を始めたときは、走査の前に、選んだフォルダのリプレイを自動で取り込みます。

監視が動いているときに「走査を始める」を押すと、確認の窓に「監視を止めてから走査します。」と出ます。
「はい」を押すと、監視を止めてから走査を始めます（監視と走査は同時に動かせないため）。
走査している間は「監視」ボタンを押せず、「監視: 走査中」と出ます。

走査している間は:

- ゲームを操作しないでください。走査の間は、ゲームへのキーボードとパッドの入力をこのツールが止めています。
- ゲームの窓をドラッグしないでください。ドラッグしている間はゲームが止まります。
- ゲームの窓は前面になくてかまいません。ほかの作業をしていても走査は進みます。
- ゲームは終了しないでください。
- 止めたいときは、上の帯の「停止」を押します。そこまでに終わった分は残ります。
  もう一度「新規のみ走査して DB 追加」で始めると、残りから続けます。

走査は、ゲームのリプレイの 25 番（`th9_25.rpy`）の枠を借りて再生します。
25 番にリプレイが入っていれば、走査の間は `th9_25.rpy.tickscan.bak` という名前で退避し、終わったら元に戻します。
途中でこのツールが止まってしまったときも、次に走査を始めたときに元に戻します。

走り方は 4 つあります。ふだんは既定の 1 つ目だけで足ります。
2〜4 つ目は記録を消したり置き換えたりするので、始める前に確認の窓に消えるものが出ます。
3・4 つ目で消えるのは、フォルダやキャラの絞り込みに関係なく、記録全体です。

| 走り方 | 使うとき |
|---|---|
| 新規のみ走査して DB 追加（既定） | まだ走査していないリプレイだけを走査します。途中で止めた走査の続きもこれです |
| 上書きして新たに走査 | 走査済みのリプレイも走査し直します。同じリプレイの前の走査の結果は、新しい結果に置き換わります |
| 実プレイは残し、走査の結果だけ消して走査 | 走査の結果をすべて消してから走査し直します。監視で記録した自分のプレイと、リプレイの登録は残ります |
| DB ごと空にして走査（実プレイも消えます） | 記録をすべて消し、リプレイのフォルダ全体の登録からやり直します。監視で記録した自分のプレイも消え、バックアップからしか戻せません |

### 6. 自分のプレイを記録する（監視）

1. 上の帯の「監視」を押します。左の印が赤い丸になれば動いています。
2. 花映塚を起動して遊びます。このツールとゲームは、どちらを先に起動してもかまいません（監視はゲームの起動を待ちます）。
3. 遊んでいる間の数字は「プレイ」タブに、終わった対戦は「履歴」タブに出ます。

止めるときは、もう一度「監視」を押します。
このツールの窓が前面にあるときは、F9 キーでも入り切りできます。
「設定」→「記録」タブの「花映塚を見つけたら監視を自動で入り切りする」を入れると、ゲームの起動と終了に合わせて監視が自動で入り切りします
（このとき「監視」ボタンは押せなくなり、「監視: 自動」と出ます）。
監視で花映塚を見つけると、そのフォルダを「ゲームのフォルダ」として自動で覚えます。

## ふだんの使い方

一度「はじめに」を済ませたら、あとは次のくり返しです。

1. 遊ぶ前に「監視」を入れておきます（「花映塚を見つけたら監視を自動で入り切りする」を入れておくと、押し忘れません）。
2. 新しく保存したリプレイは、「既存Replay一括登録」を押し直すと取り込まれます。登録済みのリプレイが二重に入ることはありません（中身が同じファイルは、別のフォルダにあっても 1 件です）。
   押し忘れを防ぐ方法が 2 つあります（どちらも「設定」→「記録」タブ。既定はどちらもオフです）:
   - 「監視を ON にしたとき Replay保存監視も一緒に入り切りする」: 監視している間にリプレイのフォルダへ保存したリプレイを、その場で登録します。
   - 「起動時に既存Replay一括登録を流す」: `EnmaCho.exe` を起動するたびに、走査の窓で選んでいるフォルダの登録が自動で 1 回流れます
     （フォルダの中で移動したリプレイも登録し直します）。
3. 取り込んだリプレイの「数値の推移」と「被弾窓」が欲しくなったら、走り方「新規のみ走査して DB 追加」で走査します。まだ走査していない分だけが走ります。

## 困ったとき

走査や監視が途中で止まったときは、上の帯にその理由の行が出ます。
それまでの経過は、`EnmaCho.exe` と同じフォルダの `data\logs\th09_log_日付.tsv` に 1 行ずつ残ります。

| 出た字・起きたこと | 直し方 |
|---|---|
| 「th09.exe が見つかりません。ゲームを起動してください。」 | 花映塚を起動してから、もう一度走査を始めます |
| 「ゲームの replay フォルダが見つかりません。」 | 下の「リプレイのフォルダを指定する」のとおり、「ゲームのフォルダ」を選びます |
| 「走査と通常の監視は同時に動かせません」 | 上の帯の「監視」を止めてから、もう一度走査を始めます |
| 「フォルダが一つも指定されていません。」 | 走査の窓の「対象にするフォルダ」の「追加…」でフォルダを選んでから、もう一度押します |
| 「設定の「リプレイのフォルダ」（…）の外にあるフォルダが選ばれています」 | 走査の窓でそのフォルダを外すか、設定の「記録」タブの追加の置き場に足してから、もう一度押します（追加の置き場を外したときや、前の版で選んだフォルダで起きます） |
| 走査が「タイトルへ戻れない」と言って止まった | ゲームを手でタイトル画面へ戻してから、もう一度走査を始めます |
| 走査が倍速にならない | 花映塚を `vpatch.exe` から起動し直します |
| 統計に何も出ない | 「自分の名前」を登録して（「はじめに」の 3）、「既存Replay一括登録」を押し直します |
| 「リプレイ」タブの「数値の推移」「被弾窓」が空 | そのリプレイがまだ走査されていません（「はじめに」の 5）。被弾窓だけが空なら、被弾窓を取らない設定で走査したか、被弾していません |
| 保存したリプレイが「リプレイ」タブに出ない | 「既存Replay一括登録」を押し直します（「ふだんの使い方」の 2） |
| 空き容量が足りなくなってきた | 「管理する」の「容量の目安」と「バックアップ」を見てください |

## リプレイのフォルダを指定する

上の帯の「設定」を押し、「記録」タブのいちばん下の 3 行で指定します。指定したら「保存」を押してください。
この 3 つを合わせたものが、このツールが扱うリプレイの範囲です。
Replay保存監視はこの全体を見張り、走査の窓の「対象にするフォルダ」はこの中から選びます。
走り方「DB ごと空にして走査」も、この全体を登録し直します。
ここの指定を変えたら、次に始める監視・Replay保存監視・一括登録・走査から効きます（動いている最中のものは、前の指定のまま動きます）。

- **ゲームのフォルダ**: 「選ぶ…」を押し、`th09.exe` のあるフォルダを選びます。
  監視で花映塚を見つけると自動で覚えるので、監視を使っていれば選ばなくてもかまいません。
  「ゲームの replay フォルダが見つかりません」と出たときは、ここを選んでください。
- **ユーザー側のデータ**: ゲームのフォルダから決まるので、表示だけです（花映塚を Program Files の下に入れているときに Windows が `%LOCALAPPDATA%\VirtualStore` の下に作るフォルダです。無ければ「ありません」と出ます）。
- **追加の置き場**: ほかの場所にリプレイを置いているときは、「足す…」を押してフォルダを選びます。いくつでも足せます。外すときは、一覧で 1 行選んで「外す」を押します。
  走査の窓で外のフォルダを選んだときに「足す」を押しても、ここに入ります。

どれも中のフォルダまで全部見ます。

- 追加の置き場は、`EnmaCho.exe` と同じフォルダの `replay_paths.txt` に 1 行に 1 つずつ入ります。メモ帳で直接書いてもかまいません（文字コードは UTF-8 のまま保存してください。`#` で始まる行は読み飛ばします）。
- 対戦ツール（adonis2）が自動保存したリプレイは、保存先がゲームのフォルダかユーザー側のデータのフォルダの中なら Replay保存監視が拾います。ほかの場所へ保存しているときは、そのフォルダを追加の置き場に足してください。
- 走査でゲームにリプレイを再生させるときは、ユーザー側のデータのフォルダに `replay` フォルダがあればそこ、無ければゲームのフォルダの `replay` フォルダの 25 番の枠を使います。

## ゲームに組み込むファイルについて

走査などでは、`native\th09_inject\build\th09_inject.exe` を使って `native\th09_tickhook\build\th09_tickhook.dll` を
ゲームのプロセスへ組み込み、毎フレームのデータを取ります。組み込んだ DLL は、ゲームを終了するまでゲームの中に残ります。
そのため、Windows のウイルス対策ソフトが警告を出すことがあります（外部プロセスのメモリを操作するツールに共通の挙動です）。
この 2 ファイルは、`EnmaCho.exe` から見て今の場所に置いたままにしてください。移したり消したりすると、走査ができません。

## 管理する

### 記録の置き場所

このツールが作るものは、既定ではすべて `EnmaCho.exe` と同じフォルダ（`Enmacho` フォルダ）の中にあります。
Windows のレジストリや、ほかのフォルダには書きません（走査で借りるゲームの 25 番の枠を除きます）。
`config.json` を直接書き換えて DB の置き場所を変えた場合は、その場所もバックアップ・移動・削除の対象にしてください。

| ファイル・フォルダ | 中身 | 消すと |
|---|---|---|
| `th09_tracker.sqlite3` | 記録の DB（登録したリプレイ、監視・走査で記録したプレイ、統計の元） | 記録がすべて無くなります |
| `data\layer0\th09_ticks.db` | 走査と監視で取った毎フレームのデータと被弾窓 | 「数値の推移」と「被弾窓」が無くなります |
| `config.json` | 設定（自分の名前、走査の窓で選んだフォルダなど） | 設定が既定に戻ります |
| `ui_settings.json` | 画面で最後に選んだ表示の覚え | 表示の選び方が既定に戻ります |
| `replay_paths.txt` | 追加の置き場 | 追加の置き場が空になります |
| `game_dir.txt` | 設定で選んだ、または監視で覚えたゲームのフォルダ | 選び直すか、次に監視したときに覚え直します |
| `data\backup\` | 走査の前に取るバックアップ | バックアップが無くなります（記録そのものは消えません） |
| `data\logs\` | 日ごとの経過の記録（困ったときに見るもの） | 消してかまいません |

どのファイルも、最初に必要になったときに作られます。
ファイルを消したり写したりするときは、先に監視と走査を止め、このツールを閉じてください。

### 容量の目安

作者の手元の記録（1,677 本・約 228 時間分）での実測です。容量のほとんどは被弾窓（被弾の前後のデータ）が占めます。

| | 合計 | 1 本あたり | 1 時間あたり |
|---|---:|---:|---:|
| 全体 | 8.7 GB | 5.2 MB | 38 MB |
| 被弾窓 | 7.8 GB | 4.6 MB | 34 MB |
| 毎フレームのデータ | 0.76 GB | 0.45 MB | 3.3 MB |
| 記録の DB | 0.09 GB | 0.05 MB | 0.4 MB |

1 本の長さや被弾の数によって増え方は変わります。
既定の設定では、記録のほかにバックアップを 1 組残すので、使う容量は上の 2 倍ほどになります。
さらに走査の前に新しいバックアップを作っている間は、古いバックアップを消す前なので、もう 1 組分の空きが要ります。

容量を減らしたいときは:

- バックアップを取らない、または古いバックアップを消す（下の「バックアップ」）。
- 被弾窓を取らない（「設定」→「被弾窓」タブの「被弾窓を取る」を外して「保存」を押す）。その後に記録・走査した分から効き、取ってある被弾窓は消えません。
  走査の窓の「被弾窓は設定と同じ（config.json）」が入っていることも確かめてください（外していると、走査の窓の指定が使われます）。

### バックアップ

- 走査の窓の「**走る前にバックアップを取る**」（既定: オフ）: 入れると、走査の前に記録の DB と毎フレームのデータを `data\backup\scan_日時\` へ写します。
  バックアップは毎フレームのデータとほぼ同じ大きさになります。入れないと容量は食いませんが、走査の途中で何かあったときに戻す先がありません。
- 設定の「記録」タブの「**バックアップは「完成した 1 つ」だけ残す（未完成のバックアップは消す）**」（既定: オン）:
  走査が新しいバックアップを取れたら、それより前のバックアップを消して、ふつうは 1 組だけ残します（新しいバックアップが前のものより極端に小さいときは、念のため前のバックアップも残します）。
  外すと、バックアップが走査のたびに増えていきます。
- 設定の「記録」タブの「**バックアップ**」の一覧: 残っているバックアップを大きさつきで出します。選んで「消す」を押すと、確認のあとで消します（走査中は消せません）。
- 走査していないときなら、`data\backup\` の中の `scan_日時` フォルダは手で消してもかまいません（記録そのものは消えません）。

バックアップから戻すときは:

1. 監視と走査を止め、このツールを閉じます。
2. 戻したい `data\backup\scan_日時\` の中に、次の 3 つが揃っているかを確かめます。
   揃っていなければ、そのバックアップは作りかけか、バックアップを取った時点でその DB がまだ無かったものなので、この手順では戻さないでください。
   - `th09_scan_backup.txt`（バックアップが最後まで取れたときにだけ作られる目印）
   - `main\th09_tracker.sqlite3`
   - `layer0\th09_ticks.db`
3. 今の記録も残しておきたいときは、`Enmacho` フォルダごと別の場所へ写しておきます。バックアップを取った後に増えた記録は、戻すと無くなります。
4. `main\th09_tracker.sqlite3` を、`EnmaCho.exe` と同じフォルダへ上書きで写します。
5. `layer0\th09_ticks.db` を、`data\layer0\` へ上書きで写します。
6. 写した先に、同じ名前で末尾が `-wal` か `-shm` のファイル（`th09_tracker.sqlite3-wal` など）があれば消します。

4 と 5 は、同じバックアップから両方を戻してください。片方だけ戻すと、記録の DB と毎フレームのデータが食い違います。

### 新しい版に入れ替える

`EnmaCho.exe` は起動したときに新しい版があるかを 1 回だけ確かめ、あれば「新しいバージョンがあります。いま更新しますか？」と聞きます。
「はい」を押すと、閉じて新しい版を入れ、開き直します。うまくいかないときの手での入れ替え方は、同じフォルダの `UPDATE.md` を見てください。

### 別の場所・別の PC へ移す

1. 監視と走査を止め、このツールと花映塚の両方を終了します。
2. `Enmacho` フォルダを丸ごと移します。記録と設定も一緒に移ります。
3. リプレイファイルそのもの（`Enmacho` フォルダの外にあるもの）は移りません。別の PC へ移すときは、リプレイも別に移してください。
4. 移した先で、走査の窓の「対象にするフォルダ」と、設定の「記録」タブのフォルダ（ゲームのフォルダ・追加の置き場）を選び直します。
5. 「既存Replay一括登録」を押して、リプレイの新しい場所を登録します（登録済みのリプレイが二重に入ることはありません）。

### 使うのをやめる

1. 監視と走査を止め、このツールと花映塚の両方を終了します。
2. 走査の途中でこのツールが止まったことがあるなら、`Enmacho` フォルダを消す前に、`EnmaCho.exe` を一度起動して閉じます。
   起動したときに、走査で借りたゲームの 25 番の枠を元に戻します（元の 25 番のリプレイは `th9_25.rpy.tickscan.bak` という名前で退避してあります）。
3. `Enmacho` フォルダを丸ごと消します。インストーラーは使っていないので、ほかに消すものはありません。

## 画面ごとの使い方

### 上の帯

- **監視**: 自分のプレイを記録します（「はじめに」の 6）。押すたびに入り切りします。
- **走査**: リプレイを自動で再生して記録する窓を開きます。
  「対象にするフォルダ」とモード・対戦区分・難易度・キャラで絞り込み、「予定を見る」で対象を確かめてから「走査を始める」を押します。
  走っている間は、上の帯の「停止」で止められます。
- **既存Replay一括登録**（走査の窓の中）: 再生はせず、「対象にするフォルダ」で選んだフォルダのリプレイファイルを読んで記録に登録だけします。
  被弾窓や数値の推移は入りませんが、リプレイ・統計のタブで一覧や集計に使えます。
- **配信パネル**: 配信用の縦長の窓（SB / PB / Target / WR）を開閉します。OBS のウィンドウキャプチャで取り込めます。
  出す項目・背景色・字の大きさは、窓を右クリックしても変えられます。
- **設定**: 下の「設定」の節を見てください。

### プレイ

ゲームを監視している間、いまの対戦の数字を表示します（読むだけのタブです）。
監視は、上の帯の「監視」、設定の「記録」タブの「花映塚を見つけたら監視を自動で入り切りする」、「監視を切り替えるキー」（F9）のどれかで入り切りします。
表示する項目は、設定の「統計」タブの「プレイタブに出す項目」で選べます。

### 履歴

記録したセッションの一覧です。上の「実プレイ」「リプレイ再生」「全て」で切り替えます。

- 行を右クリックして「個別詳細を開く」を選ぶと、そのセッションの詳細が開きます。
- 行を選んで Delete キー（または右クリック）で削除できます。確認で「はい」を押したときだけ消えます。
- 残す件数は、設定の「履歴」タブで決められます。

### リプレイ

登録したリプレイの一覧です。「Story / Extra」と「Match」で切り替え、キャラや相手、難易度などで絞り込めます。

- 「自分のみ」で自分のリプレイだけを出します。自分の名前は、設定の「記録」タブで登録します。
- 行を押すと詳細が開き、「概要」「数値の推移」「被弾窓」を見られます。数値の推移と被弾窓は、走査したリプレイだけに入ります。
- 行を右クリックすると、リプレイファイルの場所をエクスプローラーで開けます。

### 統計

記録した対戦を集計します。自キャラ・相手キャラ・タグで絞り込み、要約カードと内訳表で見ます。

- 「全組み合わせ表」で、キャラの組み合わせごとの表を開きます。
- 既定では他人のリプレイを数えません。「他人のリプレイも含める」で入れます。
- 数字の意味は、画面の「この画面の数字について」に書いてあります。
- 表の列の並び・表示は、設定の「統計」タブで変えられます。

### 設定

| タブ | 変えられるもの |
|---|---|
| 記録 | 監視の入り切り、リプレイの再生も記録するか、Replay保存監視、バックアップの残し方と一覧（選んで消せる）、起動時の一括登録、自分の名前、リプレイのフォルダ |
| 被弾窓 | 被弾窓を取るか、窓の前後の長さ、窓を取るモード |
| 履歴 | 中断・リプレイの履歴と完走の履歴を残す件数 |
| 統計 | 統計に出す区分、プレイタブに出す項目、表の列 |
| 配信 | 配信パネルに出す項目、窓の大きさ、背景色、字の大きさ |
| 目標 | 配信パネルに出す Target と WR |

## 建て方

### 記録・分析の画面（C#）

.NET SDK（`csharp/global.json` に書かれた版）が要ります。

```
dotnet publish -c Release -r win-x64 csharp/TH09.Drive/TH09.Drive.csproj
dotnet publish -c Release -r win-x64 csharp/TH09.Update/TH09.Update.csproj
dotnet publish -c Release -r win-x64 csharp/TH09.Shell/TH09.Shell.csproj
```

それぞれのプロジェクトの `bin/Release/<版>/win-x64/publish/` にできる exe と DLL を、同じフォルダに集めます（`EnmaCho.exe` と `EnmaCho_drive.exe` と `EnmaCho_update.exe` が隣どうしになるように）。`EnmaCho_update.exe` は、起動時の「いま更新しますか？」で「はい」を押したときに使う、入れ替え用の exe です。

### 注入用の 2 ファイル（C、32bit）

`th09.exe` は 32bit（PE32/i686）なので、注入する DLL とインジェクタも 32bit でビルドする必要があります。
64bit 用の MinGW では `-m32` が使えないため、**i686 版のツールチェーンが別に要ります**。

1. https://github.com/skeeto/w64devkit/releases から `w64devkit-x86-<版>.7z.exe`（自己解凍 7z）を取得します。
2. `C:\toolkit\_x86tmp` へ展開します（`C:\toolkit` へ直接展開すると、既存の 64bit 版があれば上書きします）。
3. `C:\toolkit\_x86tmp\w64devkit` を `C:\toolkit\w64devkit-i686` へ移動します。
4. 別の場所へ入れた場合は、環境変数 `TH09_I686_BIN` に `bin` ディレクトリを指定します。

準備ができたら、次の 2 本を実行します。

```
native\th09_tickhook\build.bat
native\th09_inject\build.bat
```

できた `th09_tickhook.dll` と `th09_inject.exe` は、`EnmaCho.exe` のあるフォルダの下の`native\th09_tickhook\build\` と `native\th09_inject\build\` へ、それぞれ置きます。
